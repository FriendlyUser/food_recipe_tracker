# Documentation · 文件

Guides for adopting and customizing the Biluo theme, in English and Traditional
Chinese. For the overview, quick-start, and the "where to change what" table,
see the project README ([English](../README.md) · [繁體中文](../README.zh-Hant.md)).

## English

- [Content](./en/content.md) — post frontmatter, the series data model, tags,
  and language facets.
- [Customization](./en/customization.md) — color palette, fonts, favicons.
- [Search](./en/search.md) — how Pagefind indexes the site (and why search is
  blank in `pnpm dev`).
- [Comments](./en/comments.md) — Giscus and other providers.
- [Deployment](./en/deployment.md) — Cloudflare and other static hosts.
- [SEO and crawlers](./en/seo-and-crawlers.md) — robots.txt, the AI-crawler
  policy, sitemap, social previews, llms.txt.
